# Money Village

A 3D village that tracks money lent, invested, working, in transit, in stock and held up.
Works on any device with a browser. No server, no account.

## Use it
1. Turn on GitHub Pages (Settings -> Pages -> Deploy from branch -> main / root).
2. Open the page URL on any device.
3. Data lives in that browser's local storage. Use **Export** to save your data as JSON and **Import** to load it on another device.

The AI Steward only appears inside Claude; the standalone page hides it.

## Privacy
Never commit your exported JSON. `.gitignore` blocks `*.json`. Keep the repo private.
